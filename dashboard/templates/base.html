RecyClean Admin Console
Plastic Waste Reward Management System

The RecyClean Admin Web App is used to manage plastic recycling submissions, staff accounts, rewards, and system data. It supports barangay-level monitoring and reporting through a centralized web dashboard.

System Modules
  • • Dashboard overview & KPIs
  • • Submissions & drop-off site records
  • • Staff account management
  • • Reward redemption processing
  • • DIY tutorial content management
